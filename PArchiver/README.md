# PArchiver - Современный архиватор файлов

![Version](https://img.shields.io/badge/version-1.0.0-green.svg)
![License](https://img.shields.io/badge/license-MIT-blue.svg)
![C++](https://img.shields.io/badge/C++-17-blue.svg)

**PArchiver** — это современный архиватор файлов с графическим интерфейсом, написанный на C++. 
Приложение предлагает интуитивно понятный дизайн в стиле Material Design и поддерживает множество форматов архивов.

## 🌟 Особенности

### Современный дизайн
- Интерфейс в стиле Material Design
- Плавные анимации и переходы
- Адаптивная цветовая схема
- Удобная навигация

### Поддерживаемые форматы
- **ZIP** - самый популярный формат
- **TAR** - стандартный Unix-архив
- **TAR.GZ** - сжатый TAR архив
- **TAR.BZ2** - BZ2 сжатый TAR
- **7Z** - формат 7-Zip
- **ISO** - образы дисков

### Функционал
- ✅ Создание архивов
- ✅ Распаковка архивов
- ✅ Просмотр содержимого архива
- ✅ Добавление файлов в архив
- ✅ Удаление файлов из архива
- ✅ Тестирование целостности архива
- ✅ Прогресс-бар операций
- ✅ Информация о файлах в архиве

## 🛠 Технологии

- **Язык**: C++17
- **GUI**: SFML (Simple and Fast Multimedia Library)
- **Архивация**: libarchive
- **Сборка**: CMake

## 📋 Требования

Для сборки и запуска приложения необходимо установить:

- Компилятор C++ с поддержкой C++17 (GCC 7+, Clang 5+)
- CMake 3.10+
- libarchive
- SFML 2.5+

### Установка зависимостей (Debian/Ubuntu)

```bash
sudo apt-get update
sudo apt-get install -y libarchive-dev libsfml-dev cmake g++ git
```

## 🚀 Сборка и установка

### Клонирование репозитория

```bash
git clone https://github.com/yourusername/parchiver.git
cd parchiver
```

### Сборка проекта

```bash
mkdir build
cd build
cmake ..
make -j$(nproc)
```

### Запуск приложения

```bash
./PArchiver
```

### Установка в систему

```bash
sudo make install
```

## 📖 Использование

### Создание архива

1. Нажмите кнопку **"Новый архив"** в боковой панели
2. Выберите файлы для добавления
3. Укажите имя и формат архива
4. Нажмите "Создать"

### Распаковка архива

1. Нажмите **"Открыть архив"**
2. Выберите архив для распаковки
3. Нажмите **"Распаковать"**
4. Укажите директорию назначения

### Просмотр содержимого

После открытия архива вы увидите:
- Список всех файлов в архиве
- Размер каждого файла
- Дату последнего изменения
- Тип файла (файл/папка)

## 🔧 Расширение функционала

### Добавление нового формата

Для поддержки нового формата архива修改 `archiver_core.cpp`:

```cpp
if (format == "newformat") {
    archive_write_set_format_newformat(a);
    archive_write_add_filter_compression(a);
}
```

### Добавление новой функции

1. Объявите метод в заголовочном файле
2. Реализуйте в соответствующем `.cpp` файле
3. Добавьте кнопку в UI при необходимости

## 🐛 Известные ограничения

- Drag-and-drop файлов требует дополнительной реализации
- Пароли на архивы пока не поддерживаются
- Многотомные архивы требуют доработки
